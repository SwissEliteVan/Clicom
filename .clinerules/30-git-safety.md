# Git — sécurité CLICOM

- Repo : `SwissEliteVan/clicom`.
- Ne jamais travailler dans `clicom-hostinger`.
- Ne jamais lancer `git reset --hard`.
- Ne jamais commit automatiquement.
- Ne jamais push automatiquement.
- Commit et push demandent une autorisation explicite de l'utilisateur pour l'étape concernée.
- Ne pas stage des changements sans rapport avec la tâche.
- Avant suppression/nettoyage : prouver qu'un fichier est inutilisé et préférer une opération réversible.
