# Communication avec l'utilisateur

- Réponses directes, courtes et opérationnelles.
- Ne pas produire de longs rapports intermédiaires.
- Ne pas proposer plusieurs chemins contradictoires.
- Si une information est incertaine, dire précisément laquelle et vérifier la source adaptée.
- Ne pas demander à l'utilisateur de vérifier un élément disponible dans le repo ou dans les outils de l'agent.
- Si une action nécessite hPanel et n'est pas exécutable localement, donner les clics exacts et les valeurs, sans prétendre l'avoir effectuée.
