# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please **do not** open a public GitHub issue or discussion.

Please report the issue confidentially by email:

- **Contact:** `hello@clicom.ch`

### When submitting a report, please provide:

1. A clear description of the vulnerability.
2. Step-by-step instructions to reproduce the issue (proof-of-concept if possible).
3. The estimated impact and affected components.
4. Any relevant logs or screenshots (with sensitive data redacted).

### Guidelines:

- **Confidentiality:** Please do not disclose or discuss the vulnerability publicly until it has been reviewed and addressed.
- **No Exploitation:** Do not attempt to access, modify, or destroy user or business data beyond what is strictly necessary to demonstrate the vulnerability.
- **Remediation Time:** Please allow a reasonable timeframe for the team to investigate and deploy a fix before any coordinated disclosure.

Thank you for helping keep CLICOM secure.
